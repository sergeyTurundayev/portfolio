# Портфолио Сергея Турундаева

Персональный сайт-портфолио веб-разработчика. На странице представлены навыки, примеры выполненных проектов и ссылки для связи.

## Содержание сайта

- Краткая информация о разработчике и его навыках: HTML, CSS, JavaScript, Node.js, PHP, MySQL, WordPress, Photoshop и Figma.
- Галерея проектов с переходами на опубликованные сайты.
- Контакты: Telegram, WhatsApp, Viber, LinkedIn и телефон.

## Структура проекта

- `index.html` — разметка и содержание страницы.
- `css/all.css` — стили, включая адаптацию для мобильных экранов.
- `works/` — изображения проектов в портфолио.
- `images/` — фотография и изображения страницы.
- `favicon/` — иконки сайта и связанные конфигурационные файлы.

Это статический сайт: серверная часть, установка зависимостей и сборка не требуются.

## Локальный просмотр

Из корневой папки проекта запустите простой HTTP-сервер:

```sh
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) в браузере. Для корректной загрузки изображений и стилей открывайте страницу через сервер, а не напрямую как файл.

## Обновление портфолио

Чтобы добавить проект, поместите его превью в `works/`, затем добавьте ссылку и изображение в секцию `Last works` файла `index.html`. Указывайте содержательный `alt` для превью. Стили страницы редактируются в `css/all.css`.
